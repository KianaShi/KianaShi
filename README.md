## 📦 Featured projects

### 🎭 [Shakespeare RAG](https://github.com/KianaShi/shakespeare-rag)

Structure-aware Retrieval-Augmented Generation system for searching and answering questions about Shakespeare's works.

- Implemented document loading, dialogue-aware chunking, embeddings, vector storage, and semantic retrieval
- Built a retrieval evaluation workflow to compare chunking strategies and measure retrieval quality
- Designed the project without relying heavily on high-level RAG frameworks

`Python` · `ChromaDB` · `Sentence Transformers` · `RAG` · `Retrieval Evaluation`

---

### 💳 Fraud Risk Analysis

End-to-end machine learning project for identifying potentially fraudulent applications and supporting risk-based approval decisions.

- Analyzed identity, device, location, email, and temporal features across **2,775 application records**
- Built a leakage-safe preprocessing and modeling pipeline using **Logistic Regression, Decision Tree, and Random Forest**
- Selected the final model using cross-validated **PR-AUC**, achieving **0.945 ROC-AUC**, **94.6% precision**, and **84.3% recall**
- Converted predicted fraud probabilities into **approve, decline, and manual-review** decisions through threshold and cost-benefit analysis

`Python` · `Scikit-learn` · `Pandas` · `Classification` · `PR-AUC`

---

### 🐾 [Pet Shop Data Platform](https://github.com/KianaShi/pet-shop-database)

Multi-database data management system designed for pet shop operations and analytical reporting.

- Designed a normalized relational schema covering customers, products, inventory, orders, and suppliers
- Implemented database operations and analytical queries with Python and MySQL
- Explored document and graph representations using MongoDB and Neo4j

`Python` · `MySQL` · `MongoDB` · `Neo4j` · `Database Design`
